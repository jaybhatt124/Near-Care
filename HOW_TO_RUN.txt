======================================================
  NearCares — MongoDB + Google Maps Version
  HOW TO RUN
======================================================

STEP 1 — GET A GOOGLE MAPS API KEY
─────────────────────────────────────
1. Go to https://console.cloud.google.com/
2. Create a project (or use an existing one)
3. Go to "APIs & Services" -> "Library" and enable:
     - Places API
     - Geocoding API
4. Go to "Credentials" -> "Create Credentials" -> "API Key"
5. Copy the key -> put in GOOGLE_MAPS_KEY

   Tip: restrict the key to Places API + Geocoding API only
        (Credentials -> your key -> "API restrictions")

STEP 2 — INSTALL MONGODB
──────────────────────────
Option A: Local MongoDB (free, offline)
  - Download from https://www.mongodb.com/try/download/community
  - Install and start the service
  - Default URI: mongodb://localhost:27017

Option B: MongoDB Atlas (free cloud, no install)
  - Go to https://cloud.mongodb.com
  - Create a free cluster (M0 tier — always free)
  - Click "Connect" -> get your connection string
  - Example: mongodb+srv://user:pass@cluster0.abc.mongodb.net/

STEP 3 — CONFIGURE .env
─────────────────────────
Copy .env.example to .env and fill in:

  MONGO_URI=mongodb://localhost:27017        <- or Atlas URI
  MONGO_DB=nearcares
  GOOGLE_MAPS_KEY=your_google_maps_api_key
  ADMIN_USER=admin
  ADMIN_PASS=admin123

STEP 4 — INSTALL PYTHON PACKAGES
───────────────────────────────────
  pip install flask python-dotenv requests "pymongo[srv]"

  (No mysql-connector needed anymore)

STEP 5 — RUN
──────────────
  python app.py

  Open: http://localhost:5000
  Admin: http://localhost:5000/admin

======================================================
WHAT CHANGED FROM OLD VERSION
======================================================

  MySQL              ->  MongoDB (pymongo)
  mysql.connector    ->  pymongo
  db_setup.sql       ->  Not needed (MongoDB is schema-less)
  Mappls Nearby API  ->  Google Places Text Search API
  Mappls Geocode     ->  Google Geocoding API
  Mappls Map SDK     ->  "View on Google Maps" deep link (no JS SDK needed)
  MAPPLS_REST_KEY / MAPPLS_MAP_KEY /
  MAPPLS_CLIENT_ID / MAPPLS_CLIENT_SECRET  ->  GOOGLE_MAPS_KEY (one key covers both)

  Search now also actively looks for CLINICS (not just hospitals) for
  every specialty, and clinics are ranked ahead of plain/unclassified
  hospital results (after admin-added hospitals and multispecialty
  hospitals) so nearby clinics don't get buried in the results.

======================================================
GOOGLE MAPS API ENDPOINTS USED
======================================================

  Places (Text Search): https://maps.googleapis.com/maps/api/place/textsearch/json
  Geocoding:             https://maps.googleapis.com/maps/api/geocode/json
  Reverse Geocoding:     https://maps.googleapis.com/maps/api/geocode/json (latlng param)
